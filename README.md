# Session Control Room · חדר בקרה ל-Claude Code

דשבורד מקומי בדפדפן שמראה בזמן אמת מה Claude Code עושה, ואיתו שני כלים נלווים:
- **סייר שבועי** שמחפש סקילים שימושיים לבעיות שהגדרת;
- **מערכת "שיפור עצמי"** שהופכת סרטוני טיפים להצעות שיפור, ומבצעת רק את מה שאישרת.

> ## ⚠️ הבהרה: שימוש באחריותך בלבד
> המערכת וכל רכיביה מועברים **כמו שהם (AS-IS)**, ללא תשלום.
> **היוצר אינו מתחייב לדבר**, ובכלל זה:
> - לא לתוצאות, ולא לנכונות או לשלמות של המידע המוצג;
> - לא לתאימות למחשב שלך, ולא לזמינות, לתמיכה או לעדכונים;
> - לא לעלויות של Claude או של שירותים אחרים;
> - לא לכל נזק, אובדן מידע, חיוב כספי או תקלה, ישירים או עקיפים.
>
> ההתקנה והשימוש הם באחריותך הבלעדית. ההבהרה מוצגת גם במתקין, בחלון ההפעלה, וכחלון קופץ בדפדפן בהפעלה הראשונה. ראו גם [LICENSE](LICENSE).

## 1. מה זה, בשתי דקות

**Claude Code** הוא עוזר בינה מלאכותית של Anthropic. הוא רץ על המחשב שלך: קורא וכותב קבצים, מריץ פקודות, מחפש באינטרנט ומתקין כלים. מדברים איתו בשפה רגילה (גם בעברית), בטרמינל או בתוך VS Code.

ככל שעובדים איתו יותר, מצטברים כלים, סקילים ושיחות במקביל, וקשה לדעת מה קורה. המערכת הזו עונה על שלוש שאלות:

| שאלה | הרכיב שעונה |
|---|---|
| מה Claude עושה עכשיו, ואיפה? | **חדר הבקרה** ו**העולם**: כל שיחה פעילה, מאיפה היא שואבת מידע, כמה טוקנים היא צורכת. |
| מה כדאי להוסיף לו? | **הסייר השבועי**: מחפש כלים רק לבעיות שהגדרת מראש, ובודק שהם בטוחים. |
| איך הופכים טיפים מסרטונים לשיפורים אמיתיים? | **שיפור עצמי**: סרטון → תמלול → תובנות → הצעה → אישור שלך → ביצוע. |

**עיקרון מנחה:** הדשבורד **לא צורך טוקנים** ולא עולה כסף. הוא רק קורא קבצים ש-Claude Code כבר כותב במחשב שלך. שום דבר לא מותקן בלי אישור שלך.

## 3. התקנה מאפס

נבנה ונבדק על **Windows 11**. הדשבורד עצמו (Python + דפדפן) אמור לעבוד גם ב-Mac/Linux, אבל קובצי `.cmd`, המתקין והמשימה המתוזמנת הם ל-Windows.

### 3.1 מה צריך

| רכיב | בשביל מה | חובה? |
|---|---|---|
| מנוי Claude (Pro / Max) או מפתח API של Anthropic | להפעיל את Claude Code | ✅ |
| Git for Windows | Claude Code ב-Windows נשען עליו | ✅ |
| Python 3.10 ומעלה | השרת של חדר הבקרה | ✅ |
| דפדפן (Chrome / Edge) | לצפות בדשבורד | ✅ |
| חיבור לאינטרנט | ספריית התלת-ממד של "העולם" נטענת מ-CDN | רק לעולם |
| VS Code | עבודה נוחה עם Claude | מומלץ |
| ffmpeg + faster-whisper | תמלול סרטונים | רק לשיפור עצמי |
| uv + SkillSpector | בדיקת אבטחה | רק לסייר |

### 3.2 שלב אחר שלב

**1. Git for Windows:** מורידים מ-https://git-scm.com/download/win ומתקינים עם ברירות המחדל.

**2. Python:** מורידים מ-https://www.python.org/downloads/. במסך הראשון של ההתקנה מסמנים **"Add python.exe to PATH"**.

**3. Claude Code:** פותחים PowerShell ומריצים:
```powershell
irm https://claude.ai/install.ps1 | iex
```
אחר כך מריצים `claude` ומתחברים לחשבון לפי ההוראות. מדריך רשמי: https://docs.claude.com/en/docs/claude-code

**4. הורדת המערכת:** בדף ה-GitHub של הפרויקט לוחצים **Code → Download ZIP** ופורסים לתיקייה, או:
```powershell
git clone https://github.com/m0548516135-cyber/session-control-room.git C:\tools\session-control-room
```
> 💡 עדיף נתיב באותיות לטיניות בלבד, למשל `C:\tools\session-control-room`.

**5. הרצת המתקין:** בתוך התיקייה, ב-PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```
המתקין:
- בודק מה מותקן ומה חסר, ואומר בדיוק מה להריץ;
- יוצר קובץ הגדרות מקומי (`control-room\config.json`);
- מוסיף קיצור דרך **"Session Control Room"** לשולחן העבודה.

המתקין לא מוריד ולא מתקין תוכנות בעצמו. אם משהו חסר, מתקינים אותו ומריצים את המתקין שוב.

**6. הפעלה:** לחיצה כפולה על הקיצור בשולחן העבודה (או על `control-room\start.cmd`).
- נפתח חלון שחור. **לא סוגרים אותו**, הוא השרת.
- הדפדפן נפתח על http://localhost:8790 ומציג את ההבהרה. מסמנים "קראתי והבנתי" וממשיכים.

### 3.3 רכיבים אופציונליים

**שיפור עצמי (תמלול סרטונים):**
```powershell
winget install Gyan.FFmpeg
py -m pip install faster-whisper
```

**הסייר השבועי:**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv tool install skillspector
```
אחר כך **עורכים את `control-room\scout\needs.md`** עם הבעיות שלכם (פרק 6), ומריצים את המתקין עם הדגל `-Scout`:
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Scout
```
זה רושם משימה שבועית בשם "Claude Skill Scout" (ימי ראשון, 09:00).

## 4. חדר הבקרה

**כתובת:** http://localhost:8790. נגיש רק מהמחשב עצמו, לא מהרשת.
**הפעלה:** `start.cmd`. סגירה: סוגרים את החלון השחור.

### מה הוא עושה

כל 4 שניות השרת קורא את יומני הסשנים של Claude Code מ-30 הימים האחרונים. הוא קורא רק מה שנוסף מאז הפעם הקודמת, ושומר מטמון ב-`.cache.json`. מכל יומן הוא מחלץ:
- איזה כלי הופעל, ומאיפה הגיע המידע (קבצים, אינטרנט, דפדפן, פקודות, כתיבה);
- איזה מודל רץ, וכמה טוקנים נצרכו;
- תיאור בעברית לכל פעולה ("נכנס ל-localhost", "חיפוש באינטרנט", "כותב קובץ X");
- פרטי הפעולה: קובץ, שורה שהשתנתה, חיפוש, כתובת.

בנוסף הוא קורא את הסקילים, הסוכנים, חיבורי ה-MCP והתוספים המותקנים, ואת `PROPOSALS.md`.

### הלשוניות

| לשונית | מה רואים | מה אפשר לעשות |
|---|---|---|
| **העולם** | אי תלת-ממדי חי (פרק 5). | לסובב, להתקרב, ללחוץ על בניינים. |
| **שיפור עצמי** | כמה סרטונים, תמלולים ותובנות; מה ממתין; מה בחניה; הצרכים. | צפייה. |
| **תחנות** | כל סשן פעיל: פרויקט, מודל, מקורות, פעולות אחרונות. עובד גם בלי אינטרנט. | צפייה. |
| **מחסן** | כל הסקילים לפי קטגוריות, עם גיל ושימוש בפועל. | להעביר סקיל לארכיון או להחזיר ממנו. |
| **סייר והצעות** | דוח הסייר האחרון, וההצעות מ-`PROPOSALS.md`. | לאשר הצעה בכפתור (הופך `[ ]` ל-`[x]`). |
| **תשתית** | סוכנים, שרתי MCP, תוספים, אילו פרויקטים ממופים בגרף ידע. | צפייה. |

**ארכיון סקילים:** מעביר את התיקייה מ-`~/.claude/skills/` ל-`~/.claude/skills-archive/`, כך ש-Claude כבר לא רואה את הסקיל. "החזר" מחזיר אותו.

**תיאורים בעברית לסקילים:** בקובץ `control-room\skill_he.json`. סקיל בלי תיאור שם מקבל את המשפט הראשון מהתיאור שלו.

## 5. העולם: התצוגה הוויזואלית

| מה רואים | מה זה אומר |
|---|---|
| **דמות** | סשן פעיל של Claude, בצבע של הפרויקט שלו. |
| **כובע** | המודל: כתר = Opus · כובע = Sonnet · נבט = Haiku · כוכב = Fable. |
| **בניין** | מקור מידע: ספרייה (קבצים), מגדל אינטרנט, בית כרום (דפדפן), מפעל פקודות, סדנת כתיבה, נמל (כלים חיצוניים), מטה (סוכנים). |
| **שלט מתחת לבניין** | הפעולה האחרונה שבוצעה שם. |
| **בית בצבע פרויקט** | פרויקט פעיל. סשן שמחכה לך הולך הביתה ומציג "Zz". |
| **אסם הטוקנים** | טוקנים היום, ביחס ליום הכבד ביותר. |
| **יום / לילה** | לפי השעה אצלך. |

סשנים סגורים לא מוצגים.

**לחיצה על בניין** פותחת את "בתוך המפעל": אנימציה של **הפעולות האמיתיות** שבוצעו שם. למשל הספרן שולף את הקובץ שנקרא, סדנת הכתיבה מוחקת את השורה הישנה וכותבת את החדשה, ובית הכרום מציג צילומי מסך אמיתיים מהדיסק.

> **מגבלה:** המערכת יודעת מה Claude **ביקש** לעשות (הקלט), אבל לא תמיד מה הוא **קיבל** (הפלט). "התוצר" שמוצג הוא תיאור לפי סוג הכלי.

## 6. הסייר השבועי

**איפה:** `control-room\scout\` · **מתי:** ימי ראשון 09:00 · **פלט:** `control-room\scout.json`, מוצג בלשונית "סייר והצעות".

הסייר **לא מחפש "מה חדש ומגניב"**. הוא מחפש **רק** פתרונות לבעיות שכתובות ב-`scout\needs.md`. בלי רשימה, הוא לא מחפש כלום.

| קובץ | תפקיד |
|---|---|
| `needs.md` | **הקובץ היחיד שעורכים.** בעיות לפי פרויקט. בעיה שנפתרה מוחקים. |
| `prompt.md` | ההוראות לסייר. לא צריך לגעת. |
| `scan.py` | מריץ את SkillSpector דרך Python (עוקף חסימה של Windows על קובצי exe). |
| `run_scout.cmd` | מריץ את Claude במצב לא-אינטראקטיבי, עם Sonnet ורשימת כלים מוגבלת. |
| `last_run.log` | יומן הריצה האחרונה. כאן מסתכלים כשמשהו נכשל. |

**בכל ריצה הסייר:**
1. קורא את `needs.md` ואת רשימת הסקילים המותקנים;
2. מחפש עד 5 מועמדים מ-60 הימים האחרונים;
3. פוסל מה שדורש שירות בתשלום או סיסמאות, או שנראה כמו הונאה;
4. מוריד כל מועמד לתיקייה זמנית ומריץ עליו SkillSpector;
5. כותב דוח בעברית.

> **הסייר אף פעם לא מתקין כלום.** הוא רק ממליץ.

**עלות:** כל ריצה היא סשן אחד של Claude (Sonnet), פעם בשבוע, ונספרת במכסה שלך.
**ריצה ידנית לבדיקה:** לחיצה כפולה על `scout\run_scout.cmd`.

## 7. מערכת שיפור עצמי

**איפה:** `self-improvement\`

```
 סרטון  ──►  תמלול  ──►  תובנות  ──►  מסנן רלוונטיות  ──►  הצעה  ──►  אישור [x]  ──►  ביצוע + תיעוד
(videos/) (transcripts/) (insights/)   (needs.md)       (PROPOSALS.md)  (אתה)      (/apply → CHANGELOG.md)
```

### איך משתמשים

1. שמים סרטון בתיקייה `self-improvement\videos\`.
2. פותחים Claude **בתיקייה `self-improvement`** (ב-VS Code: File → Open Folder, או בטרמינל: `cd self-improvement` ואז `claude`).
3. מקלידים **`/improve`**. Claude:
   - מתמלל מקומית ובחינם;
   - כותב תובנות;
   - **מאמת כל כלי שהוזכר** (אמיתי? בטוח? מי פרסם?);
   - מסנן לפי `needs.md` ומוסיף **עד 3 הצעות** ל-`PROPOSALS.md`. השאר נכנס ל"חניה".
4. מסמנים `[x]` בהצעות הרצויות (בקובץ, או בכפתור "אשר" בחדר הבקרה).
5. מקלידים **`/apply`**. Claude:
   - מבצע רק הצעות מסומנות עם תג `AUTO`;
   - בהצעות `MANUAL` נותן הוראות במקום לבצע;
   - רושם כל ביצוע ב-`CHANGELOG.md`.

### פורמט הצעה (לא לשנות, חדר הבקרה מזהה לפיו)

```markdown
- [ ] **P-001** `AUTO` · S · 🟢 — **כותרת קצרה**
  → הסבר · פרויקט: <שם> · `source: <סרטון>`
```

| קובץ | תפקיד |
|---|---|
| `system\process.md` | ספר החוקים של התהליך. |
| `system\transcribe.sh` | תמלול כל הסרטונים החדשים (`bash system/transcribe.sh small`). |
| `system\faster_transcribe.py` | התמלול עצמו (faster-whisper, על המעבד). |
| `.claude\commands\` | הגדרת `/improve` ו-`/apply`. |

## 8. טוקנים, אמינות ופרטיות

**טוקנים:** בשרת אין שום קריאה ל-Claude או לבינה מלאכותית אחרת, ואין שליחת מידע החוצה. מהאינטרנט נטענים רק הגופן וספריית התלת-ממד. צריכת המשאבים קטנה מאוד: בסביבות 2% מליבת מעבד אחת ו-30MB זיכרון. **יוצא דופן:** הסייר השבועי (פרק 6).

**אמינות:** כל פעולה שמוצגת נלקחת מיומני הסשנים האמיתיים. האקראיות היחידה בקוד היא קישוטית: איפה דמות מופיעה על האי, ועשן מהארובות.

**פרטיות:** חדר הבקרה קורא את **כל** השיחות שלך עם Claude, **במחשב שלך בלבד**. הקבצים הבאים פרטיים, ו-`.gitignore` כבר מונע מהם להיכנס ל-Git:
- `control-room\.cache.json`: תקציר הסשנים שלך;
- `control-room\scout.json`, `scout\last_run.log`;
- `control-room\config.json`;
- התוכן של `self-improvement\videos`, `transcripts`, `insights`, `logs`.

**אבטחה:**
1. שום דבר לא מותקן בלי אישור אנושי.
2. כל סקיל של צד שלישי עובר SkillSpector לפני התקנה. ציון גבוה לא פוסל אוטומטית: בודקים ידנית אם זו התרעת שווא.
3. תוכן מסרטונים ומהאינטרנט הוא מידע, לא הוראות.
4. השרת מאזין רק ל-`127.0.0.1`.
