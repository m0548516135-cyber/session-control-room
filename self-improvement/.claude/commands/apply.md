עבוד לפי `system/process.md` שלב 4.

1. קרא את `PROPOSALS.md` ואתר את כל ההצעות המסומנות `[x]` שעדיין לא בוצעו.
2. עבור כל הצעה מסומנת:
   - אם היא `AUTO` — בצע אותה מקצה לקצה (צור/ערוך קבצים, התקן סקיל/פקודה/הוק, עדכן settings וכו').
     לפני פעולות לא-הפיכות או חיצוניות — ודא שזה בטוח. סיים בעדכון הסטטוס ל-`✅ DONE (YYYY-MM-DD)`.
   - אם היא `MANUAL` — אל תבצע. במקום זאת תן לי הוראות מדויקות צעד-אחר-צעד, וסמן `⏳ WAITING (משתמש)`.
   - אם ביצוע נכשל — סמן `⚠️ FAILED` + סיבה קצרה. אל תמחק את ההצעה.
3. לכל הצעה שבוצעה בהצלחה, הוסף שורה ל-`CHANGELOG.md`:
   `- YYYY-MM-DD — P-NNN — <כותרת> — <מה נעשה בפועל / קבצים שהושפעו>`
4. בסיום הצג סיכום: מה בוצע, מה ממתין לי, ומה נכשל.

חשוב: בצע אך ורק הצעות שאני סימנתי. אל תבצע הצעות לא-מסומנות.
