עבוד לפי `system/process.md` שלבים 1–3.

1. הרץ `bash system/transcribe.sh small` כדי לתמלל כל סרטון חדש בתיקייה. דווח מה תומלל ומה דולג.
2. לכל תמלול חדש ב-`transcripts/` שעדיין אין לו קובץ תובנות, צור `insights/<שם>.md` לפי שלב 2.
   - תקן "Cloud" → "Claude" כשברור מההקשר.
3. **אמת כל כלי שהוזכר, מיד.** חפש באינטרנט את המאגר (repo) האמיתי ובדוק בטיחות: מי פרסם, רישיון, כוכבים, האם רץ מקומית או שולח מידע החוצה. ואז סווג:
   - אמיתי + בטוח + אפשר לבצע לבד → הצעת `AUTO`.
   - אמיתי אבל דורש חשבון / מפתח / החלטה → הצעת `MANUAL`.
   - הונאה / לא קיים / מיותר / מסוכן → **🚫 דילוג** עם הסיבה.
4. העבר כל הצעה דרך מסנן הרלוונטיות (שלב 2.5 ב-`process.md`): לכל היותר 3 הצעות חדשות לריצה, והשאר ל"🅿️ חניה".
5. הוסף ל-`PROPOSALS.md` בפורמט המדויק (מזהה רץ, תג, מאמץ, סיכון, מקור). אל תיצור כפילויות.
6. בסיום הצג סיכום קצר: כמה סרטונים עובדו, וטבלת ההצעות החדשות (מזהה, תג, מה זה עושה).
   המשתמש יסמן `[x]` (בקובץ או בכפתור "אשר" בחדר הבקרה) ויריץ `/apply`.

אל תבצע אף הצעה בשלב הזה. רק להציע.
